# Docs

One page per task, for the latest release. Developer documents (the protocol, the store format, the threat model) live in the [sealctl repository](https://github.com/sealctl/sealctl/tree/main/docs) and are linked, not copied.

The docs are being written alongside the phone version ({{release.phoneVersion}}). Pages in grey in the list arrive with it. Available now:

- [Install](/install): every system, and how to verify a download.
- [Moving from the Ledger version](/docs/from-ledger): what to do if you use sealctl {{release.current}} today.
- [Leaving sealctl](/docs/leaving): hand everything back under passwords of your own.
- [Paying for sealctl](/docs/paying): what `sealctl buy` will do.
- [Cryptographic design](/crypto): the design on one page, with diagrams.

For the current release, the [README](https://github.com/sealctl/sealctl#readme) is the full guide.
