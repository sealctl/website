Install

Install the command line tool

Every command below installs the latest release. sealctl is not released yet; once it is, these commands install it.

  1. macOS (Homebrew)
  2. Debian and Ubuntu
  3. Fedora, RHEL, Rocky and openSUSE
  4. Arch Linux
  5. Nix
  6. Any Linux (tarball)
  7. From source
  8. Verify a download
  9. Completions, upgrade, uninstall, next step

macOS (Homebrew)

brew install sealctl/tap/sealctl

Also works with Homebrew on Linux. Apple silicon and Intel.

Debian and Ubuntu (.deb)

Download sealctl_<version>-1_amd64.deb (or _arm64.deb) from the latest release, then:

sudo apt install ./sealctl_*_amd64.deb

Fedora, RHEL, Rocky and openSUSE (.rpm)

Download sealctl-<version>-1.x86_64.rpm (or .aarch64.rpm) from the latest release, then:

sudo dnf install ./sealctl-*.x86_64.rpm

openSUSE:

sudo zypper install --allow-unsigned-rpm ./sealctl-*.x86_64.rpm

Arch Linux (PKGBUILD)

Each release carries a PKGBUILD. Download it from the latest release into an empty folder, then:

makepkg -si

Nix

nix profile install github:sealctl/sealctl

Any Linux (tarball)

Download sealctl-<version>-x86_64-unknown-linux-gnu.tar.gz (or aarch64-unknown-linux-gnu) from the latest release, then:

tar -xzf sealctl-*-unknown-linux-gnu.tar.gz && sudo install -m 0755 sealctl /usr/local/bin/

Linux binaries are built on Rocky Linux 9 (glibc 2.34) for x86_64 and aarch64. Backups need restic; Linux volumes need cryptsetup.

From source

cargo install --locked --git https://github.com/sealctl/sealctl sealctl

On Linux, building needs libudev-dev libdbus-1-dev pkg-config.

Verify a download

Each release has SHA256SUMS. Put it next to what you downloaded:

shasum -a 256 -c SHA256SUMS --ignore-missing      # macOS
sha256sum -c SHA256SUMS --ignore-missing          # Linux

Completions, upgrade, uninstall

  • Shell completions: sealctl completions zsh (or bash, fish) prints a script for your shell's completion folder.
  • Upgrade: brew upgrade sealctl, or install the newer package the same way.
  • Uninstall: brew uninstall sealctl/tap/sealctl, sudo apt remove sealctl or sudo dnf remove sealctl. To hand your data back first, see Leaving sealctl.
